========================================
  Sisbackup Client v2.7.0 - Portable
========================================

SYSTEM REQUIREMENTS:
  - Windows 10 22H2+ atau Windows 11
  - PowerShell 5.1+
  - rclone (auto-download saat pertama run)

CARA PAKAI:
  1. Extract folder ini ke mana saja
  2. Klik kanan "SisbackupClient.exe.ps1" → Run with PowerShell
  3. Browser akan terbuka dengan UI Sisbackup
  4. Masukkan alamat server sekolah (contoh: http://192.168.1.100:3001)
  5. Login → Pilih folder → Backup!

CATATAN:
  - Aplikasi berjalan di tray (browser)
  - Close browser untuk keluar
  - Semua config disimpan di browser localStorage
  - rclone di-download otomatis saat pertama kali run
